How these work

01 / one page per instrument

No build step, no framework

Each tool is a single HTML file in its own repository, served by GitHub Pages. Read the source in one sitting.

02 / plain-text protocols

The page isn't the only interface

Boards speak short line-based commands like SET 2.4 and MEAS, so a serial terminal or a Python script works just as well. Every repo documents its protocol in PROTOCOL.md.

03 / browser APIs, not drivers

Web Serial and WebUSB

Both are built into Chrome and Edge and ask permission before touching a port. No per-OS driver installs.

04 / firmware included

Everything to rebuild it

Each repo ships the microcontroller code (mostly CircuitPython) plus wiring diagrams in wiring/.
