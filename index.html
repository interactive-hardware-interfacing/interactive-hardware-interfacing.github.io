Instruments that run in the browser and talk to real hardware.

Open a page, plug in a board, click Connect. Each tool here drives a device over USB using the browser's own serial and USB APIs, so there is nothing to install and it doesn't matter what computer you're on.

Works in Chrome and Edge. Every tool also has a demo mode that needs no hardware.

How these work

One page per instrument

Each tool is a single HTML file in its own repository, served by GitHub Pages. No build step, no framework. View source and you have the whole thing.

Plain-text protocols

Boards speak short line-based commands (SET 2.4, MEAS). The same commands work from a serial terminal or a Python script, so a tool's page is never the only way in.

Browser APIs, not drivers

Web Serial for USB-serial boards and instruments; WebUSB where a device needs it. Both are built into Chrome and Edge and ask for permission before touching a port.
